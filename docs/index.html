Mapear para la memoria del barrio

El mapa guarda la foto, no la película. Cuatro prácticas para que guarde el cambio:

Si un local cierra, no lo borresMárcalo como disused:shop=*.
Si llega otro negocio, edita el mismo puntoAsí el cambio se confirma el doble de veces que al borrar y crear.
Pon fechascheck_date y opening_date: hoy solo el 5 % de los cambios las tiene.
Mapea el comercio popularTiendas, talleres, ventas. Loreto, en Medellín, tiene cero comercios mapeados.
